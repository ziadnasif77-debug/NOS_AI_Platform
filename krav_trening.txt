# Sporing av treningsløp er fint å ha, men mlflow (full) krever
# pyarrow<19, som KOLLIDERER med datasets/label-studio i dette miljøet
# (de krever pyarrow>=21/22). Å installere mlflow her ødelegger datasets.
#
# Løkken kjører helt fint UTEN mlflow: kjor_treningslop.py logger da
# antall korreksjoner, CER (live/kandidat) og port-utfall til stdout og
# data/logger/trening.ut.log i stedet.
#
# Vil du likevel ha MLflow-grensesnittet, installer det i et EGET,
# isolert virtuelt miljø (ikke sammen med label-studio/datasets):
#   python -m venv .venv-mlflow
#   .venv-mlflow\Scripts\pip install "mlflow==2.19.0"
# og pek det mot samme filstore for å se løpene:
#   .venv-mlflow\Scripts\mlflow ui --backend-store-uri ./data/mlflow
