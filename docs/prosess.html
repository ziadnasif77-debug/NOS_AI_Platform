Hvordan ett dokument flyter gjennom systemet

Velg en dokumenttype og klikk deg gjennom stegene — én boks om gangen. Diagrammet lyser opp der filen er akkurat nå; pilene viser bare veien videre, de er ikke egne steg. Dårlige lesinger forlater hovedløypa og går inn i treningsløkka, der MLflow sporer hvert løp og en kvalitetsport slipper bare bedre modeller til produksjon. Systemet lagrer aldri dokumentet.

MLflow Hvor det ligger og hvordan du bruker det

MLflow henger bare på treningsløkka (boks C/MLflow) — ikke på leseløypa og ikke på den isolerte serveren. Hver gang kjor_treningslop.py kjører, logges løpet: antall korreksjoner, treningstap, varighet. Åpen kildekode (Apache 2.0), kjører 100 % lokalt.

# start web-grensesnittet (lokalt, ingen sky): mlflow ui --backend-store-uri ./data/mlflow # åpne så i nettleser: http://localhost:5000

Port Kvalitetsport før produksjon

Trening lager en kandidat, ikke en live modell. Porten måler tegnfeilrate (CER) for kandidat vs live på et fast valideringssett og promoterer bare hvis kandidaten er minst like god. En dårlig korreksjonsbatch stoppes i porten — ikke i produksjon.

# mål kandidat mot live: python skript/valider_modell.py # angre siste promotering umiddelbart: python skript/valider_modell.py --rull-tilbake

Forrige live tas vare på i modeller/norhand-forrige for rull-tilbake. Valideringssettet ligger i data/validering/norhand.json — et lite, stabilt sett holdt atskilt fra treningsdataene.

Drift Kjøring uten Docker

Serveren kjører som en Windows-tjeneste via Oppgaveplanleggeren (NAV-Dokument-API): starter ved oppstart, restarter ved krasj.

powershell -File installer_tjeneste.ps1

Ukentlig trening (NAV-Trening-ukentlig) er GPU-vennlig: 8 GB rekker ikke til server + trening samtidig, så jobben stopper serveren → trener → starter serveren igjen (omstarten laster den nytrente modellen — samme feedback-pil som i diagrammet).

powershell -File installer_trening.ps1 -Dag Sunday -Klokke 03:00

Isolert server (uten internett): pakk_for_offline.py → installer_offline.py → sjekk_miljo.py. Alt er wheels, ingen containere å overføre.

Ett dokument · lest én gang · lagret aldri — bare dårlige lesinger etterlater et spor, og bare til modellen har lært av dem.
