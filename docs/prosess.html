MLflow Hvor det ligger og hvordan du bruker det

MLflow henger bare på treningsløkka (steg C) — ikke på leseløypa og ikke på den isolerte serveren. Hver gang kjor_treningslop.py kjører, logges løpet: antall korreksjoner, treningstap, varighet. Åpen kildekode (Apache 2.0), kjører 100 % lokalt.

# start web-grensesnittet (lokalt, ingen sky): mlflow ui --backend-store-uri ./data/mlflow # åpne så i nettleser: http://localhost:5000

Drift Kjøring uten Docker

Serveren kjører som en Windows-tjeneste via Oppgaveplanleggeren (NAV-Dokument-API): starter ved oppstart, restarter ved krasj.

powershell -File installer_tjeneste.ps1

Ukentlig trening (NAV-Trening-ukentlig) er GPU-vennlig: 8 GB rekker ikke til server + trening samtidig, så jobben stopper serveren → trener → starter serveren igjen (omstarten laster den nytrente modellen — samme feedback-pil som i diagrammet).

powershell -File installer_trening.ps1 -Dag Sunday -Klokke 03:00

Isolert server (uten internett): pakk_for_offline.py → installer_offline.py → sjekk_miljo.py. Alt er wheels, ingen containere å overføre.

Ett dokument · lest én gang · lagret aldri — bare dårlige lesinger etterlater et spor, og bare til modellen har lært av dem.
